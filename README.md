# Nuestra historia — Isaac & Andrea

Libro digital romántico, estático y adaptable a móviles.

## Publicación con GitHub Pages
1. En el repositorio, abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/(root)**.
4. Guarda los cambios. GitHub publicará el sitio en:
   https://zackcrwn.github.io/nuestra-historia-andrea/

## Archivos
- `index.html`: portada y capítulos narrativos.
- `style.css`: identidad visual y diseño adaptable.
- `script.js`: navegación y pequeñas interacciones.

Los siguientes capítulos se incorporarán a esta misma estructura sin borrar los anteriores.
